## 📋 How to Deploy Your Profile README

### Step 1: Create the Profile Repository
1. Go to [github.com/new](https://github.com/new)
2. **Repository name** must be exactly: `TusharSingh1705` (same as your username)
3. Make it **Public**
4. ✅ Check "Add a README file"
5. Click **Create repository**

> ✨ You already have this repo! Just update the `README.md` inside it.

### Step 2: Paste the README
1. Open your `TusharSingh1705` repository
2. Click on `README.md`
3. Click the ✏️ **Edit** button (pencil icon)
4. **Delete all existing content**
5. **Paste** the entire contents of the `README.md` file from this project
6. Click **Commit changes**

### Step 3: Enable the Snake Animation
1. In your `TusharSingh1705` repository, create the folder: `.github/workflows/`
2. Create a file called `snake.yml` inside it
3. Paste the contents from `.github/workflows/snake.yml` in this project
4. Go to your repo → **Settings** → **Actions** → **General**
5. Under "Workflow permissions", select **Read and write permissions**
6. Click **Save**
7. Go to **Actions** tab → Click **Generate Snake Animation** → Click **Run workflow**

### Step 4: Verify
1. Go to your GitHub profile: [github.com/TusharSingh1705](https://github.com/TusharSingh1705)
2. You should see your beautiful space-themed README! 🌌
